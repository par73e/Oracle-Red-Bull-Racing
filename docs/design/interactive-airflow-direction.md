# 双车气流与环境：实现方向

这是现有 AERO 模型页的功能扩展，沿用字体、红色控制和近景视角，不更换视觉身份。用户已明确授权自主实现全部需求，无需等待额外方案选择。采用代码直接构建与实景关系参考，不生成冒充实拍的背景。

访客模式：Experience，操作滑块观察赛车与气流变化。第一屏为风洞内的完整赛车，右侧保留四组机械／气流控制，左侧提供车型及风洞／Eau Rouge／Raidillon／检视场景选择；气流信息从属于车辆，不堆砌数值卡片。窄屏使用上方车辆画面与下方两列控制，全部输入可用。

标志性交互：连续拖动车速、转向、轮速或 DRS 时，在保留清晰车辆几何的同时，从各车独立 CFD 速度场计算流线的形状与运动。关键节点是真实离线算例，中间态采用明确标注的稀疏加性响应近似。多个因素的高阶相互作用未被完整求解，不声称工程精度或瞬态 CFD。

风洞为原创功能空间，收缩段在车头上游，车后为扩散方向，滚带与地面参照明确。斯帕用真实三维地形关系表现谷底左转、右转上坡和坡顶左转，2021／2023 环境分开；几何、地形及建筑是参考公开实景的近似，无法取得测绘数据时不伪造精确坐标。远景按深度虚化，车辆保持清晰。

性能与失败状态：单个流场批量读入；用户拖动时不运行求解器。数据未完成或网络失败必须显示不可用与重试，不能退回假流场。场景切换释放几何和纹理；计算按专用虚拟机内四核顺序进行，不打开 Blender。桌面与窄屏实看，检查零速、手动轮速、最高速、双向转向、DRS、车型和所有场景切换。
