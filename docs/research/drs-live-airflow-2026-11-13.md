# DRS 移动期间的气流更新修复

问题来自 Web Worker 结果回传后的姿态比较：计算耗时期间 DRS 已继续移动，结果被当作过期丢弃；提交新任务时又隐藏原流线，所以持续移动期间无法看到更新。

修复后，同一车型按顺序显示最近完成的流线，同时继续提交最新输入；停止移动后收敛到最终开度。关闭气流、零速度、切换车型及失效加载的隔离检查保留。工况文件加载期间使用已有离线种子的代理近似，新文件就绪后按缓存修订号重算，无须再次拖动。仍是异步流线预览，并非实时 CFD；可能短暂落后于尾翼姿态。

验证：

- 调度回归覆盖移动中持续显示、最新输入合并、加载时近似、新字段到达后的更新，以及停用和过期车型隔离。
- `npm --prefix web run validate:worker`：上述回归与两车六组线程前后流线几何一致性检查通过。
- `npm --prefix web run build` 通过，保留既有主包体积提示。
- Ego Lite 实测两车的打开和关闭按钮：移动期间流线始终可见，观察到多个中间开度的几何变化，最终结果到达 0%/100%。详见同名 JSON。
- 实际鼠标连续拖动 RB16B DRS 滑块，54 帧采样中保持可见，出现 14 个不同的已计算开度；释放后等待最终 100% 结果成功。详见 `drs-drag-2026-11-13.json`。

本地开发服务器已恢复在 5173 端口运行。未操作原有 CFD 计算队列。浏览器测试 Space 已结束。
