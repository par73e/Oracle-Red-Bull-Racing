# RB16B / RB19 首轮模型与材质检查

检查日期：2026-11-08。范围是本地资产结构、比例风险、部件可动性、底部几何和现有材质的显示基准。结论：两车可继续用于展示原型；尚未通过真车几何还原、可动部件或气动计算输入的验收。

## 可打开的检查副本

- [RB19 检查副本](../../assets/working/rb19/rb19-review.blend)
- [RB16B 检查副本](../../assets/working/rb16b/rb16b-review.blend)

两个副本添加了相同的摄影棚地面、相机和三盏区域灯，设置为材质预览。原始下载、源文件及原有 `rb19.blend` / `rb16b.blend` 没有覆盖。

为了比较灯光和构图，检查副本通过父级整体变换，将最长方向统一为 5.5 Blender 单位。这是展示尺度，不是经核实的真车长度；没有修改原网格坐标，也没有完成物理单位标定。

## 几何与部件

| 检查项 | RB19 | RB16B |
| --- | --- | --- |
| 原车网格对象数，不含检查场景 | 1 | 315 |
| 当前修改器求值后的三角面数 | 674,992 | 256,249 |
| 原始包围盒宽 × 长 × 高，Blender 单位 | 1.3867 × 3.7368 × 0.8054 | 0.02044 × 0.05514 × 0.01168 |
| 骨架 / 已存动画 | 0 / 无 | 0 / 无 |
| 部件情况 | 车体合并为 `Full Body_Baked`，基础网格含 123 个不相连部分 | 机械件、贴花、仪表和部分替代状态混在多个对象中 |
| DRS 准备情况 | 没有独立命名的 DRS 对象；不能直接旋转整车网格实现开合 | 有 `drs*` 对象，也有 `TAG_DRS*` 仪表标记；不能把所有名字含 DRS 的对象都当作尾翼 |
| 底部观察 | 可见简化的底板、导流片与后部轮廓；目前几何不足以证明 RB19 文丘里通道的真实形状 | 有底板、破损状态命名和扩散器对象；需要区分主状态与替代状态 |

RB19 约 67 万三角面来自当前细分等修改器求值；基础网格为 22,198 顶点、20,944 多边形。面数多不等于真车细节准确，网页导出还需要另做性能预算。

基础网格边检查得到 RB19 1,808 条边界边、1,812 条非流形边；RB16B 各 122,255 条。开放贴花、分离面片与导入结构会产生这些计数，不能直接据此断言模型损坏。但目前没有证明两车形成封闭的计算表面，不能直接作为已验收的 CFD 网格。

两份文件都声明公制、单位比例为 1，但包围盒长度明显不一致。真实尺寸与轴距应在确定赛季、分站和升级版本后，用可信尺寸资料重新标定。此轮没有完成照片叠合、轴距测量或真车 CAD 比对，车名与涂装也不能单独证明底层几何准确。

## 现有贴图与材质

RB19 的在用材质包含四张已打包、可读取的 4096 × 4096 贴图：颜色、金属度、法线、粗糙度。文件内还有旧的外部图像引用，其中 40 条缺失引用不等于当前在用车身贴图缺失。保留的旧路径含其他车型名称，只能说明来源文件存在历史数据，不能据此认定车体身份。

RB16B 有 33 个在用材质，61 个图像节点可读取，对应外部图像均在本地。没有必要先购买或重找整套涂装。首次 FBX 导入的材质接线存在明显错误：车漆颜色通道使用了 `ac_specular.dds`，轮胎颜色通道使用了模糊法线图，多个实体表面还继承了不合适的透明度或金属参数。

仅在 RB16B 检查副本中进行了以下初步修正：

- 车漆、细节、轮胎、碳纤维、轮毂改接现有相应的颜色图；轮胎和碳纤维法线通过 Normal Map 节点接入。
- 颜色图使用 sRGB，法线使用 Non-Color。按材质类别设置初步粗糙度与金属度，保留贴花的透明通道。
- 隐藏 8 个 `RIM_BLUR_*` 旋转轮毂替代网格，展示静态车轮；对象仍保留在文件内。
- 修正导入材质的镜面强度等默认值。参数用于初步目视校准，不代表实测物理参数。

RB19 原材质保持不变，作为比较基准。当前仍有偏亮的车漆/轮胎反光、RB16B 贴花与碳纤维细节不足等问题；这批低采样基准图不是最终写实成品。

## 后续制作顺序

1. 先选定每车的具体外形参考版本，用侧视、俯视与底部资料检查外形，标定单位。RB19 底板应单独复核，不能根据现有简化底面宣称真实地面效应。
2. 清理并分组机械件、贴花及替代状态；确认尾翼活动襟翼、固定主翼、连杆和旋转轴，再制作 DRS。
3. 依据已修正的材质基准，进一步校准哑光车漆、碳纤维和橡胶，再决定是否需要新增贴图。
4. 外观资产稳定后做网页模型优化，并建立专门的气流近似几何与明确的模拟假设。现有检查没有运行 CFD，也没有获得可信升力/阻力系数。
