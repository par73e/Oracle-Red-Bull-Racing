# 铺装与地形接边修复 — 2026-11-12

Sir 的俯视截图显示彩色缓冲区及辅路有锯齿缺块。复现后确认两个原因：草地与宽铺装使用不同高度，弯外侧发生穿插；涂层与基层间隔约 5mm，相机拉远后固定 0.025m 近裁面导致深度精度不足，出现层间闪烁。

`web/src/spa-surface.js` 统一道路、缓冲区、辅路和周边地形的横断面。主赛道中心线、高程、路宽数据保持原样；铺装外侧采用展示用 2% 排水横坡，平滑接至 DEM。地形采用 2.5m 显示网格，这不增加源数据精度。宽铺装增加横向细分，树木和护栏地脚同步贴合地面；曲线投影经过迭代校正，避免用源折线投影时引入弯外侧高度误差。

涂层增加深度偏移，相机近裁面按观察距离在 0.025–0.5m 内适配。车辆尺度及 CFD 参数未改动。

验证结果：

- `npm --prefix web run validate:spa` 与构建通过，原有双车尺度和轮胎接地检查通过。
- 新增三角面内部采样及 BVH 回归检查，242,440 处样本覆盖主路、缓冲区、辅路、五条涂层和双侧路肩，没有地形穿透。基层与草地最小间距约 45mm，涂层相对基层最小间距约 4.38mm。
- 网页复查约 100m/145m 高空俯视、地面上方侧视和默认坡底视角，均未复现截图缺块。前后图为 `seams-before.png`、`seams-after-top.png`、`seams-after-side.png`、`seams-after-hero.png`。
- 本机桌面 1440×900、DPR 1.5、关闭气流时，120 帧约 29.1FPS；未发现页面异常或失败资源。此次未重测手机和气流开启时的性能；数值记录在 `seams-browser-qa.json`。
- 未启动 Blender，未停止或改动原有 CFD 队列。本轮浏览器任务已正常结束。
