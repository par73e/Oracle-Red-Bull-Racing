# 粗网格 vs 细网格 + 棱柱边界层精算体检报告（2026-11-22）

## 1. 算例配置与资源实测

- **运行环境**：`aero-cfd` OrbStack Linux VM（9 核 / 7.8 GiB 内存），OpenFOAM 14，6 核并行（`mpirun -np 6`）。
- **网格升级**：
  - 背景网格 `(88 36 24)` → `(116 48 32)`（基元 `0.66 m → 0.50 m`）；
  - 车体/四轮表面加密 `level (3 4)`（`41 mm`）→ `level (4 5)`（`15.6 mm`），叠加 `underbody` / `frontWing` / `rearWing` 4 级体加密；
  - 启用 `addLayers true`（目标 4 层棱柱边界层，实测车身平均有效 `1.06–1.07` 层、厚度覆盖 `23.6%–24.5%`）；
  - 全部 3 例均零网格质量报错（`Mesh OK.`，最大非正交性 `< 65°`，最大偏斜度 `< 4.0`）。
- **数值格式与收敛**：动量项由一阶 `bounded Gauss upwind` 升级为二阶 `bounded Gauss linearUpwind grad(U)`，SIMPLE 升级为 SIMPLEC（`consistent yes`，2 次非正交修正），迭代步数 `650 → 1000` 步，力值取末 150 步均值。
- **单算例开销实测**：
  - `rb16b-refined-base`：`1,352,193` 单元，约 `49 分钟`，磁盘 **`337 MB`**；
  - `rb16b-refined-open`：`1,355,541` 单元，约 `42 分钟`，磁盘 **`338 MB`**；
  - `rb19-refined-base`：`1,416,096` 单元，约 `46 分钟`，磁盘 **`354 MB`**。
  - **推算第二步（双车 16–20 例核心主干精算集）**：总占盘仅约 **`5.5–7.0 GiB`**（远低于剩余 `118 GiB`），连续求解耗时约 **`12–15 小时`**（适合夜间 `/goal` 无人值守分批跑完）。

### 关键观察：RB16B DRS 减阻/减下压力变化
- 粗网格（41 mm）：DRS 开启带来阻力 `-178.2 N (-7.5%)`、下压力 `-239.2 N (-18.1%)`；
- 细网格（15.6 mm + 棱柱层）：DRS 开启带来阻力 `-38.5 N (-1.9%)`、下压力 `-69.0 N (-5.7%)`。
- **原因**：粗网格 41 mm 体素在尾翼主/副翼缝隙处有堵塞效应，放大了闭合态的假阻力；加密到 15.6 mm 后真实缝隙被分辨出来，同时暴露了展示用第三方模型尾翼翼型攻角/弦长偏克制的客观几何特征。

## 4. 核心结论与决策依据

1. **量级差异源于展示几何本身，而非网格太粗**：即使网格加密 **8 倍**、贴壁 $y^+$ 降低 3 倍、动量升级为二阶格式，两车在 180 km/h 下的纯 OpenFOAM 下压力仍稳定在 **`~764 N`（RB19）与 `~1208 N`（RB16B）**（阻力 `2074–2470 N`，升阻比 `0.31–0.58`），证明这是 Sketchfab 展示模型本身的简化底板/翼型几何的真实求解结果，不存在“粗网格把下压力算丢 5 倍”的数值崩塌。
2. **细网格对流场细节（尤其 RB16B 底板与直行对称性）提升显著**：
   - RB16B 直行侧向假力由 `+27.2 N` 降至 `-1.8 N`；
   - RB16B 底板流线在粗网格下因 41 mm 体素堵塞导致大量路径截断（与细网格偏差 P90 达 `30–41 cm`），细网格显著打通了底板有效流道；
   - 阻力数值波动（`dragPtp`）减半，二阶格式大幅降低一阶迎风假阻力（RB16B 阻力降 `13.2%`）。
3. **存储完全可控，时间适合分批/夜间执行**：单算例仅占 `~340 MB` 磁盘、耗时约 `42–49 分钟`。后续双车 16–20 例核心主干精算集仅需 `~6–7 GiB` 磁盘，总求解时间约 `12–15 小时`。
