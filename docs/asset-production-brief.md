# 网页模型制作范围

依据 Sir 在 2026-11-08 的六点标注执行。

- 以现有 RB16B、RB19 为基础，优先真实的材质与灯光质感。
- 四轮自转；前轮可转向，后轮不转向。悬挂与车身保持静止。
- DRS 采用活动翼片、固定主翼、执行器缸体与伸缩杆的联动。采用参考机构的近似尺寸，不声称车队 CAD 复原。
- RB19 底板只补基本地面效应通道，不追逐分站升级。RB16B 保留其自身年代的底板。
- 统一制作尺度，保留网页镜头缩放。性能在资产和页面完成后测量。
- 保留源文件，制作文件另存，交付可加载的 GLB 与控制说明。

## 本地验收页设计

视觉：冷灰摄影棚、哑光深色车体、克制的红色操作强调，赛车占据主要画面。

内容：全屏车模为主；车型选择、DRS、车轮、转向控制集中在一个简洁的检查区；署名与素材来源可以展开。

交互：平滑镜头切换；DRS 与执行器同步；前轮转向与四轮转动独立控制。尊重减少动态效果设置。
