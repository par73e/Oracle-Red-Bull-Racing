# 侧箱与前悬挂局部计算（2026-11-11）

本研究面向 RB19 和 RB16B 的侧箱下方、侧箱上沿及前悬挂附近。两车分别使用现有中立位计算代理，在独立目录进行 180 km/h、直行、DRS 关闭、轮速匹配的探索性稳态 RANS 计算；不覆盖原模型或原流场。当前结果不代表车队 CAD、真实赛车性能或经风洞验证的空气动力。

## 几何审计

`audit_proxy.py` 在三个坐标盒内各抽取 500 个原展示三角面中心，计算其到体素代理的最近距离。盒子也包括其他零件，抽样不是按表面积加权，不能作为零件误差统计或通道贯通证明。结果和两种表面哈希见 `rb19-proxy-audit.json` 与 `rb16b-proxy-audit.json`。示例：RB19 侧箱下方盒内距离中位数约 5.7 mm、90 百分位约 13.7 mm；前悬挂盒内分别约 7.4 mm 和 16.0 mm。已有 12.5 mm 体素闭合及填洞可能改变薄悬挂、侧箱开口和狭窄通道。

`check_proxy_channel.py` 在两侧宽坐标盒中以 50 mm 间隔检查代理的体素外空间连通。两车两侧均找到前后相通的格点，但盒子包含车辆外侧空间，网格过粗也可能漏掉细通道，原展示网格并非完整封闭；**不能因此断言截图中的窄通道真实贯通或与赛车一致**。结果见各车 `*-coarse-channel-connectivity.json`。

## 算例与质量

`prepare.py` 从各车 base 复制条件及本车代理，在底板、两侧侧箱和前悬挂坐标盒实施 level 5 局部细化。盒子不是精确的独立零件分区；没有棱柱边界层。两车均通过基本 `checkMesh`、单流体区域检查；RB19 为 1,142,623 单元，RB16B 为 1,124,642 单元。RB19 从本车旧底板加密 1150 步场映射初值；RB16B 从本车旧底板加密 1150 步场映射初值，采用保守松弛和无非正交显式修正。两车从新网格的 0 步计算到 650，再明确从 650 接续至 1150；原场与日志保留。两个输出都是稳态 RANS 的迭代结果，而非瞬态模拟。

- RB19：1150 步初始残差 Uy 约 3.19e-4，压力首轮约 6.15e-4；局部连续性误差约 2.97e-7。末 100 步整车竖向力均值约 -247 N、峰峰值约 54 N，波动明显，**未充分收敛**。
- RB16B：1150 步初始残差 Uy 约 1.97e-4，压力约 1.38e-3；局部连续性误差约 8.69e-7。末 100 步整车竖向力均值约 -950 N、峰峰值约 14 N，仍需更充分收敛审查。
- 两车 1150 步 body y+ 均跨越接近零至约 5000；没有近壁棱柱层，不保证壁面函数适用于所有位置。高残差、力波动和 y+ 均不能因 Mesh OK 而忽略。上述力仅用于数值稳定性观察，不是赛车性能估计。

`make_sampler.py` 将新旧 1150 步场取样到相同 105 × 105 × 47 的物理点网格。`compare.py` 只比较两边均有有效值的点，区域盒包含车外空气，且旧场的底板局部细化与新场侧箱细化配置不同，因此**不是网格无关性或误差上界证明**。共同点速度矢量差的中位数：RB19 侧箱下方约 4.36、上沿约 5.29、前悬挂盒约 4.57 m/s；RB16B 分别约 3.82、3.47、3.54 m/s。详见两份 `*-comparison.json`。

## 网页显示和局限

`pack.py` 保存局部采样与有效掩码，`web/public/flow/<car>/sidepod.*` 包含源采样与代理哈希。网页针对实际展示模型的表面射线和前部转向拉杆附近布置候选起点，要求代理场有有效采样；沿局部场积分，碰撞或无效采样处终止。空间盒和高度只用于布点及统计，不能说明每条线都贴合真正侧箱通道或完整悬挂；外向射线与逐线段三角面检查也不构成所有起点位于闭合展示体之外的证明。

180 km/h、直行、DRS 关闭、轮速匹配的状态使用该车对应的局部加密基线；其他工况使用速度缩放与原粗网格工况差分近似。粗场无有效差分的位置沿用速度缩放基线，不包含该位置的工况响应；页面明确标注。并未对侧箱、前悬挂的其他工况做新的加密 CFD 求解，不能用这批线判断 DRS 的真实影响。零流速且车轮静止时不显示流线。

`npm run validate:sidepod` 检查文件哈希、尺寸、有效掩码、来源几何哈希，以及两车的基线、DRS、低速、组合与转轮等有限工况的所绘线段三角面交叉；这不是所有连续工况或物理正确性的证明。页面在参数连续变化时暂缓局部线重建，稳定后更新；浏览器观察到 DRS 切换结束后的稳定帧率约 29 fps，取决于机器、视角和模型。

完整网格、求解场、原始取样和失败记录保留在本机被忽略的 `cfd/library/cases/`；网页二进制和元数据为展示采样。两车本轮计算与采样结束，专用 `aero-cfd` 已停止。未提交、推送或部署。
