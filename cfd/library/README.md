# 双车型离线流场库

网页实时显示预先计算的速度场，不在拖动时启动 OpenFOAM。RB19 与 RB16B 分别计算，不能互换套用。

每车 9 个关键工况：

|键|入口速度|轮周速度|机构状态|
|---|---:|---:|---|
|low|50 km/h|随车速|直行、DRS 关闭|
|base|180 km/h|随车速|直行、DRS 关闭|
|high|350 km/h|随车速|直行、DRS 关闭|
|open|180 km/h|随车速|DRS 完全打开|
|left / right|180 km/h|随车速|转向控制分别 -18° / +18°|
|locked|180 km/h|0|四轮停止|
|fast|180 km/h|100 m/s|四轮超速|
|spin|0|50 m/s|静止车身、四轮转动|

前轮实际转角来自网页相同的机构求解；轮心、含外倾的轴线和半径由当前姿态导出。前轮参考 RPM 决定共同轮周速度，后轮按自己的半径计算角速度，不把不同半径硬设成同一 RPM。网页 RPM 上限对应约 100 m/s 轮周速度。

## 复现

在项目根目录，先按 `cfd/README.md` 配置专用 `aero-cfd` 环境及主机 Python 环境。模型文件仍为本地资产，需保留当前 GLB。

```bash
bash cfd/library/scripts/prepare_all.sh
cfd/.venv/bin/python cfd/library/scripts/run_all.py
cfd/.venv/bin/python cfd/library/scripts/summarize_library.py
cd web
npm run validate:airflow
npm run build
```

`prepare_all.sh` 调用 Node 直接导出 GLB 的真实机构姿态，再创建独立的 12.5 mm 封闭体素计算副本；不启动 Blender，不覆盖 GLB 或 blend 文件。几何、全量算例和失败试算留在被 Git 忽略的 `geometry/` 与 `cases/`。每例四个求解进程、串行执行，虚拟地址空间限制 6 GiB。再次执行会使用已完成的网格和结果，不擅自覆盖它们；修改配置需要新算例或显式保留原例后重建。

`create_case.py` 生成 Foundation 14 的 k-omega SST 稳态 RANS 算例。车身无滑移、四轮旋转壁面、移动地面、正面均匀入口，空气运动黏度 1.5e-5 m²/s。域为 `[-20,38] × [-12,12] × [0,16]` m，约 16–18 万单元、一阶迎风、无棱柱边界层。RB16B 狭缝使初始设置不稳定，重算使用更保守的松弛；转向及独立轮速工况另外关闭非正交显式修正。具体 `fvSchemes` 与 `fvSolution` 留在每例 system 目录，不能假定所有数值设置完全一样。

每例先通过 Mesh OK，再求解、重建和取样。发散或广泛速度异常会中止，不发布该例。RB16B 最早的基线、转向和停止车轮失败日志保留在名称含 `failed` / `rejected` 的算例目录，没有作为网页数据。

## 网页插值

统一物理网格为 88 × 34 × 32，范围 `[-4,9] × [-1.65,1.65] × [0.025,1.65]` m。CFD 坐标 X 向车后、Y 向车右、Z 向上，网页为 `(-Y,Z,-X)`；计算副本下移 5 mm 的偏移另计。取样速度以 int16 加每例比例保存，每车约 5 MB。manifest 记录来源 GLB 与计算表面哈希、SI 单位、网格、残差、异常采样与数据哈希。

速度在 50、180、350 km/h 的归一化速度场之间连续变化；DRS、转向、轮速采用各自相对基线的加性差分响应。低速逐渐转向静止旋转轮场，静止转向的前轮局部场作坐标变形。零来流与零轮速时严格停止。所有关键节点可复现对应算例，中间开度和多个输入同时变化是稀疏代理近似，缺少高阶耦合，也不保证插值场严格守恒。

网页对混合后的速度场做三线性取样和流线积分。轮胎保守体积与真实三角面碰撞会终止穿入固体的路径；固体／无效样本为零。流线运动按局部速度的飞行时间计算，颜色范围末端表示 120 m/s 及以上。网页不把这些预览换算成赛车阻力、下压力或性能结论。

## 科学与场景边界

`reports/library-quality.md` 和 JSON 记录逐例残差、守恒、末 100 步力波动及异常采样。有限值与固定迭代步数并不等于严格收敛。孤立的数值高速尖峰会作为无效点排除，记录原始最大值及数量；广泛异常整例拒绝。原始全场仍保留，不能把显示字段当作未经处理的原始数据。

原模型不是工程 CAD，体素化会改变薄翼、缝隙、内部通道和轮地接触；粗网格、无边界层、壁面函数与一阶迎风都限制可信度。没有网格／计算域独立性、瞬态模拟或实验验证。350 km/h 仍采用不可压近似，其误差尚未量化；不应声称真实 F1 性能精度。

风洞房间是原创三维展示，计算域为自由外流，没有该房间壁面。斯帕道路、坡度、建筑与年份布置参考公开场景关系，非测绘模型；没有真实弯道气流、侧风、偏航、转弯载荷或动态车身姿态的 CFD。林木透明素材由内置 imagegen 生成，具体提示词和来源文件在 `web/public/environments/`。背景做深度虚化，车辆保持清晰，房间与地形仍保留遮挡。
