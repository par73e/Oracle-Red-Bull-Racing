# 静止正迎风 CFD

RB19 与 RB16B 各自在原有中立姿态粗网格上计算 0.5、1、2、5、15 m/s 正迎风。边界设定为地面速度 0 m/s、四轮角速度 0 rad/s、前轮回正、DRS 关闭。入口湍流强度按 1% 设定，使用与现有速度序列相同的下限及尺度。求解器采用 OpenFOAM Foundation 14 的稳态 k-ω SST，并保留原有的 650 步设置。

```sh
cfd/.venv/bin/python -u cfd/library/stationary/run.py
```

脚本在 `aero-cfd` VM 中逐例运行，每例四个求解进程。算例保存在 `cfd/library/cases/<车型>-stationary-<工况>/`，包括边界条件、求解日志和原始采样。`cfd/library/reports/<车型>-stationary-*.json` 记录网格指纹、残差、连续性误差、采样数量和发布文件 SHA-256。`web/public/flow/<车型>/stationary/manifest.json` 列出可读取的档位。

网页直接读取已求解档位的采样速度矢量。相邻算例之间采用正权重线性插值，零风速端点的速度场为零。底板和侧箱保持独立播种，但与整车流线共享该粗网格速度场。每条线在显示模型上检查碰撞，遇到采样域边界或无效数据处停止。页面上的气动力数字仍来自原有估算器。

这些算例共享各车原粗网格，几何、近壁分辨率、入口湍流设定和稳态 RANS 均限制结论。RB16B 在低风速的压力残差高于 RB19。双车均缺少独立网格验证和实验对照。行驶、侧风、DRS 打开和转向工况使用各自的现有数据路径。

## RB19 固定 10 km/h 的迎风对照

`run_road010.py` 复现自然风 0、4、11、15 m/s 的四个 RB19 工况。地面与轮周速度均为 10 km/h，前轮回正、DRS 关闭，来流为车速与自然迎风之和。算例及采样原件位于 `cfd/library/cases/rb19-headwind-audit-road010-*`，网页文件位于 `web/public/flow/rb19/road010/`。

旧版用分别围绕 180 km/h 基准计算的来流轴、地面轴做差分。固定车速 10 km/h、自然风 0、4、11 m/s 时，旧组合场的车尾整车流线高度 P90 依次为 1.540、1.415、1.381 m。网页从匹配工况追踪的高度约为 1.383、1.385、1.386 m。流线高度取决于速度场和渲染采样。车速为 10 km/h 的直行工况直接读取这些结果或在相邻自然风节点间插值。其他行驶速度仍受原有工况覆盖限制。

整车、底板、侧箱可以共享匹配工况的速度场。底板流线只显示在原有底板采样窗口内，离开窗口时结束追踪。后段覆盖与整车高度分开验收。
